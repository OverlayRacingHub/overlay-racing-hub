# Overlay Racing Hub

Overlays personalizáveis para o iRacing.

## Download
**[Baixar a versão mais recente](https://github.com/OverlayRacingHub/overlay-racing-hub/releases/latest)**: em **Assets**, baixe o instalador (.exe).

## Instalação e atualização
- Windows 11. Não precisa de permissão de administrador.
- Para atualizar, instale a versão nova por cima: overlays, configurações e perfis são mantidos.
- Como o app ainda não tem assinatura digital, o Windows pode mostrar "O Windows protegeu o computador". Clique em **Mais informações** e depois em **Executar assim mesmo**.

## Segurança e privacidade
- O app só lê os dados de telemetria que o próprio iRacing disponibiliza para overlays (somente leitura). Ele não modifica o jogo nem envia comandos para ele.
- Nenhum dado pessoal é coletado ou enviado.

## Apoie o projeto
Use o botão **Apoie este projeto.** dentro do app.
